# ORBIT | أوربت

غرفة قيادة عربية لمراقبة برامج ProfAlfailakawi. **المراقبة لا تعني أن البرنامج سليم حتى تتوفر أدلة حية موثوقة.**

## التشغيل الآمن

1. اضبط متغير البيئة `ORBIT_OPERATOR_PASSKEY` على الخادم بقيمة **فريدة وطويلة (16 حرفًا على الأقل)**. لا تضعها في GitHub أو كود الواجهة أو ملفات عامة.
2. شغّل `npm ci` ثم `npm run lint` و`npm test` و`npm run build` قبل النشر.
3. شغّل `npm start` عبر HTTPS في الإنتاج. الجلسة الحالية محفوظة في ذاكرة عملية الخادم وتنتهي بعد 8 ساعات؛ إعادة تشغيل الخادم تتطلب تسجيل الدخول من جديد.
4. إذا ظهرت رسالة تطلب إعداد رمز المشغل، اضبط متغير البيئة لدى مزود الاستضافة وأعد تشغيل الخدمة. **الرمز التجريبي السابق لم يعد يعمل في هذه النسخة.**
5. لا تمنح ORBIT أذونات كتابة على مستودعات البرامج الـ11. عند الحاجة لقراءة المستودعات الخاصة، استخدم رمز GitHub محدود الصلاحيات عبر `GITHUB_READ_ONLY_TOKEN`.

## صدق البيانات

**تحذير مهم:** `src/core/seedData.ts` يحتوي على أمثلة تجريبية تشمل حالات أعطال، نجاح فحوصات، نسب تغطية، طوابع زمنية، واتصالات تبدو موثقة. هذه ليست إثباتًا مباشرًا على صحة الأنظمة الفعلية. لا تعتمد عليها في القرارات التشغيلية أو تعلن أن كل البرامج سليمة بناءً عليها. ينبغي فصل وضع العرض التجريبي عن بيانات الإنتاج قبل الاعتماد النهائي.

- `Live`: نتيجة فحص حديث موثق للمصدر المحدد فقط؛ فحص GitHub لا يثبت سلامة الموقع أو تجربة المستخدم.
- `Cached`: لقطة قديمة أو محفوظة؛ لا تعني الحالة الحالية.
- `Demo`: بيانات توضيحية لا تمثل واقعة حقيقية.
- `Unknown`: لم يجر فحص موثوق.

## حدود الأمان

- لا تلمس إعدادات الدفع أو الإشعارات أو بيانات المستخدمين أو نشر التطبيقات الأصلية.
- عمليات اختبار الدفع والإشعارات يجب أن تكون بمحاكاة معزولة فقط.
- لا تنشر ORBIT للاستخدام الحقيقي قبل اختبار المصادقة وحماية جميع نقاط API والتأكد من قواعد Firebase وصحة مصدر كل مؤشر.

## فحص الإصدار

تشغّل GitHub Actions فحوص TypeScript والاختبارات والبناء على طلبات الدمج والدفع إلى الفرع الرئيسي. نجاحها لا يحل محل الاختبار اليدوي للأمان أو التحقق من البيانات الحية.
