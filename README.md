# ORBIT | أوربت

غرفة عمليات عربية خاصة لمراقبة أسطول البرامج بأدلة قابلة للتتبع، من دون تعديل المستودعات المراقبة أو دمج أو نشر تغييرات عليها.

## ما يعمل فعليًا

- صفحة واحدة: لكل برنامج سطر واحد (اسمه وحالته)، وأي مشكلة فيها زر «انسخ» يجهّز تقريرًا كاملًا تلصقه حيث تشاء (كلود أو غيره).
- زر أعلى الصفحة ينسخ كل المشاكل دفعة واحدة.
- دخول خاص بخادم ORBIT عبر `ORBIT_OPERATOR_PASSKEY` وجلسة HTTP-only.
- قراءة GitHub (المستودعات وعمليات Actions وآخر تعديل) بصلاحية قراءة فقط، مع فحص رابط الموقع.
- عند فتح الصفحة يُجرى الربط تلقائيًا إن لم يُتحقق من البرامج أو كانت بياناتها أقدم من 6 ساعات، وإن تعذر الربط يُكتب السبب تحت البرنامج.
- إضافة برنامج بالاسم والرابط فقط، وإزالة ما أضفته.
- استقبال أحداث حساسات مصادق عليها ومقيدة لكل برنامج مع تنقية البيانات (واجهة برمجية فقط).
- **زائر آلي بمتصفح حقيقي** كل يوم: يفتح كل موقع على سطح المكتب وعلى جوال وعلى جوال باتصال ضعيف، ويتبع بضع صفحات داخلية، ويفحص: أخطاء JavaScript، صفحة فارغة، تجاوز عرض الجوال، صور مكسورة، نصوص منسية (`Lorem ipsum`، `undefined`، `NaN`)، اتجاه RTL، أسماء الأزرار لقارئ الشاشة، رؤوس الأمان، مفاتيح مسرّبة في الملفات، وتغيّر شكل الصفحة الرئيسية عن الأمس.
- **إنذار مبكر قبل العطل**: يتعلم أوربت سرعة كل موقع وحجم صفحته المعتادين وينبّه عند التباطؤ المستمر، ويفحص شهادة HTTPS ويحذّر قبل 14 يومًا من انتهائها.
- **تقرير يكفي كلود لإصلاح الخطأ**: يشمل السبب الجذري المحتمل، وآخر تعديل سبق بداية المشكلة، وما فعله الزائر قبل الخطأ وموضعه في الكود (إن رُكّب الحساس).
- **زر «اشرح»** على كل برنامج: الخطورة وماذا يحدث للزائر وأول خطوة، بـ Gemini إن ضُبط المفتاح وبقواعد ثابتة إن لم يُضبط.
- **مراقبة المراقِب**: إن صمتت المراقبة التلقائية أكثر من 90 دقيقة يظهر تنبيه أعلى الصفحة، ويمكن ربط `ORBIT_HEARTBEAT_URL` بخدمة خارجية تنبّهك على جوالك إن توقفت.
- PWA وRTL ووضعان فاتح وداكن حسب جهازك.

لا يعني نجاح GitHub أو غياب الحوادث أن الموقع الإنتاجي سليم. «يعمل» تعني أن GitHub مربوط وأن الموقع استجاب ولا يوجد فحص فاشل؛ رحلة المستخدم الكاملة لا تُختبر.

## التشغيل المحلي

```bash
cp .env.example .env
npm ci
npm run dev
```

يجب إعداد `ORBIT_OPERATOR_PASSKEY` بقيمة عشوائية لا تقل عن 16 محرفًا. لا تضع مفاتيح الحساس أو GitHub أو Gemini في متغيرات Vite أو كود المتصفح.

## التحقق

```bash
npm run check
ORBIT_OPERATOR_PASSKEY="<test-passkey>" PORT=3100 npm run dev
```

ثم في طرفية أخرى:

```bash
ORBIT_OPERATOR_PASSKEY="<test-passkey>" node scripts/visual-smoke.mjs
```

## تركيب حساس المتصفح (اختياري، لكل موقع بموافقتك)

أضف هذا السطر قبل `</body>` في الموقع المراقَب. بدونه لا يرى أوربت ما يحدث للمستخدمين أثناء الاستخدام، بل ما يراه الزائر الآلي فقط. لا يُرسل الحساس نصًا كتبه المستخدم ولا روابط بمعاملاتها:

```html
<script src="https://orbitq8.web.app/orbit-sensor.js" async></script>
```

يُبلَّغ عن خطأ برمجي من كود الموقع نفسه من أول زائر، وعن غيره عند زائرَين مختلفين. ذاكرة التجميع تُمسح مع إعادة تشغيل الخادم، فالنتائج تُحفظ على سجل البرنامج 6 ساعات.

## حدود صريحة

- لا يوجد بعد زائر ذكاء اصطناعي يسجّل الدخول ويستخدم الموقع بحساب اختبار، ولا فحص لانتهاء النطاق (domain) أو توكنات API. الموجود: متصفح حقيقي يتبع الروابط العامة فقط.

- أوربت يقرأ ويقترح فقط؛ لا يعدّل البرامج المراقبة ولا يدمج ولا ينشر عنها.
- لا تُركب الحساسات في البرامج المراقبة دون موافقة مستقلة.
- النشر الإنتاجي يدوي من GitHub Actions (**Deploy ORBIT production**) ويُوثَّق في [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).
