# ORBIT ONE — صفحة واحدة للمالك

التنقل اليومي فيه **صفحة واحدة فقط** تجمع الحالة والحوادث والبرامج. لا تظهر تبويبات الرادار أو البرامج أو المزيد. زر ترس صغير للخيارات، و«للمختص التقني فقط» يفتح أدوات التشخيص والعمليات القديمة داخل لوحة مؤقتة يمكن إغلاقها والعودة إلى نفس الصفحة، دون حذف المحرك.

- **الحوادث**: كل الحالات الإنتاجية المؤكدة ذات الأدلة، تُعرض وتنسخ مهمة إصلاحها من الرئيسية نفسها. أي تفاصيل بسيطة تفتح داخل البطاقة، والقائمة يمكن توسيعها دون صفحة ثانية.
- **البرامج**: قائمة واحدة قابلة للبحث والتصفية، مع إضافة برنامج جديد من الاسم والرابط فقط. الربط الحقيقي يظل مشروطاً بأدلة ولا يُعتبر تلقائياً نشطاً.
- **واجهة المختص**: أقسام الرادار والأسطول والتحليلات والحماية/الاختبارات موجودة في الطبقة التقنية المخفية وراء إعدادات > للمختص التقني فقط.
- **الحماية**: لا تغييرات تلقائية على مستودعات البرامج المراقبة أو وظائفها أو الدفع أو المستخدمين.
- **التحقق**: اختبار المتصفح يؤكد اختفاء nav القديمة، ووجود صفحة واحدة، وفتح نموذج الإضافة والحوارات التقنية والهاتف.
- **الحدود**: لا يوجد ربط إنتاجي شامل للحساسات، ولا خدمة Push تعمل بعد إغلاق الصفحة، ولا مسار نشر إنتاج موثق في المستودع.
