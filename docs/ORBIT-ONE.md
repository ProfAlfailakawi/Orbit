# ORBIT ONE — غرفة عمليات هادئة

الواجهة اليومية موجّهة لمالك البرامج لا للمبرمج. تُعرض حالة البرامج والحوادث والإشارات بطريقة مختصرة، مع الاحتفاظ بكل أدوات الرادار والإدارة والرؤى والحماية المتقدمة.

## تعريف ما يظهر في الواجهة

- **مشكلة مؤكدة**: حادثة غير مغلقة بحالة Live، ومعها حدث Live مطابق في بيئة production. تجارب Canary أو البيانات Demo وCached مستبعدة.
- **تجربة أساسية موثقة**: البرنامج متصل بمصدر Live وproduction URL موثّق، وهناك إثبات بأن الموقع متاح وأن تجربة المستخدم الأساسية ناجحة. لا تعني هذه الحالة اختبار كل وظيفة أو الدفع.
- **رصد غير مكتمل**: لم تتحقق جميع الشروط أعلاه. لا يجوز عرض حالة خضراء أو «كل شيء سليم» بناء على غياب الحوادث فقط.
- **مصادر الإشارات**: أعداد أحداث إنتاج موثقة من العيون الثلاث، وليست مقياس اكتمال التغطية.
- **زر نسخ المهمة**: يستعمل Claude Mission Pack الحالي مع الأدلة والحواجز القائمة، ولا يغير مستودعات البرامج.
- **تنبيهات المتصفح**: opt-in بعد إذن المستخدم، تعمل عند فتح ORBIT في متصفح يدعم Notifications، للأحداث الحرجة والمهمة الجديدة فقط. ليست Web Push خلفية ولا تضمن إشعار الهاتف عند إغلاق الصفحة.

## ما يزال يلزم للانتقال إلى مراقبة إنتاج شاملة

1. استضافة ORBIT production رسمية، واختبار URL بعد النشر.
2. ربط آمن مستقل ومختبر لكل تطبيق لإرسال telemetry الحقيقية وتأكيد نتائج العمليات المهمة، بموافقة صاحب كل برنامج.
3. فحوص synthetic journeys غير مدمرة لكل برنامج، مع إثبات النتائج ومصدرها.
4. Web Push خارج المتصفح أو قناة إشعارات مُدارة، Watchdog مستقل، استمرارية تخزين وصلاحيات الأسرار.
5. دورة اختبار بعد الإصلاح على نسخة production، بدون تغييرات آلية أو بيانات مستخدمين فعلية.

## ضوابط لا تُكسر

كل المستودعات المراقَبة مستقلة؛ ORBIT يستقبل بيانات ويقرأ GitHub فقط. لا يعدّل الدفع أو الوظائف أو الإشعارات أو صلاحيات المستخدمين أو يقوم بدمج أو نشر على البرامج المراقبة تلقائياً. لا تُظهر بيانات ديمو كما لو كانت Live.
